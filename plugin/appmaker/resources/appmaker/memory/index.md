# Memory Index

Karpathy-style project wiki index. Keep short. Link to durable knowledge only.

## Core Pages

- `wiki/architecture.md` — system shape, boundaries, important flows
- `wiki/domain-model.md` — domain entities, invariants, glossary-adjacent concepts
- `wiki/testing.md` — test strategy, fast loops, known seams
- `wiki/integration-gotchas.md` — APIs, services, auth, data, deployment traps
- `wiki/feature-index.md` — shipped feature summaries and links

## Raw Inputs

- `raw/` — transcripts, incident notes, logs, review excerpts. Optional. Not always loaded.

## Maintenance Rules

- Update via archive/diagnose/checklist, not every conversation turn.
- Prefer synthesis over dumps.
- Cite source artifacts: PRD, retro, diagnosis, context packet, review.
- Mark uncertain claims explicitly.
